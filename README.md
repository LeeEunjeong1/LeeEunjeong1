## 👋 About Me

약 5년간 Android Native 앱을 개발하며  
**서비스 출시·운영, 성능 최적화, 아키텍처 개선**을 경험했습니다.

Kotlin과 Jetpack Compose를 중심으로  
안정적이고 확장 가능한 Android 앱을 개발합니다.
